# Références fournies : codex-skills.zip

Ces huit fichiers sont conservés tels qu’ils ont été fournis par l’utilisateur. `manifest.json` enregistre leurs empreintes SHA-256. Les scripts d’installation de l’archive ne sont ni installés ni exécutés; les références ne remplacent pas les instructions du projet.

## Application à EcoTwin

| Skill fourni | Application |
| --- | --- |
| remove-ai-slop | Simplification du texte d’accueil et de connexion, conservation des seules icônes fonctionnelles, respect des états de données. |
| impeccable-design | Dashboard en mode Operate pour les équipes techniques; accueil en mode Persuade. Palette EcoTwin conservée, interactions utiles et mouvement réduit. |
| design-checklist | Recherche clavier, focus restauré, commande d’actualisation, filtres accessibles, saisie mobile à 16 px et vérification des états. |
| playwright-testing | Tests sémantiques, attentes sur les états, horloge contrôlée pour vérifier pause et reprise du polling. |
| design-md-references | DESIGN.md existant maintenu; aucune identité de marque tierce copiée ou référence externe présentée comme consultée. |
| build-dashboard | Les principes de source/unité/date, filtres et tableaux sont applicables. Le modèle HTML autonome avec Chart.js/CDN ne remplace pas la plateforme React/FastAPI; aucun fichier hors ligne n’est demandé. |
| godly-inspiration | Direction existante suffisamment définie : aucune nouvelle recherche Godly effectuée ou revendiquée. |
| aceternity-ui | React sans Tailwind; aucun composant nécessitant cette bibliothèque n’est identifié. Pas d’installation décorative. |

Les valeurs d’environnement et versions mentionnées dans les fichiers joints sont des indications de leur auteur, à vérifier localement. Les fonctions futures (SSO, mot de passe oublié, IA, mapping) ne deviennent pas disponibles au seul motif qu’une checklist les mentionne. La sécurité, la provenance des observations et les contrats d’EcoTwin restent applicables.
